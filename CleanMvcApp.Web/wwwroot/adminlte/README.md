# AdminLTE Assets

Download AdminLTE 3 from: https://adminlte.io/

Extract and place the contents here so the structure matches:

```
wwwroot/
  adminlte/
    dist/
      css/
        adminlte.min.css
      js/
        adminlte.min.js
      img/
        AdminLTELogo.png
        user2-160x160.jpg
    plugins/
      bootstrap/
        js/
          bootstrap.bundle.min.js
      fontawesome-free/
        css/
          all.min.css
      jquery/
        jquery.min.js
      jquery-validation/
        jquery.validate.min.js
      jquery-validation-unobtrusive/
        jquery.validate.unobtrusive.min.js
```

## Quick Download via npm (run from CleanMvcApp.Web folder)

```
npm install admin-lte@^3.2
```

Then copy node_modules/admin-lte to wwwroot/adminlte
